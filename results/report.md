# HEVC tile 边界与逐 CTU 码量实验报告

## 结论

- C++ 解析器从真实码流的 SPS/PPS 得到：`1024x512`、亮度/色度均为
  `10 bit`、`4:2:0`、`Main 10`、CTU `64x64`，CTU 网格 `16x8`。
- 六种 tile 布局的实际码率控制在 `10.504-10.620 Mbps`，文件大小相差
  约 `1.1%`。整帧亮度 PSNR 为 `32.5868-32.6064 dB`，布局间差异小于
  `0.02 dB`。
- 所有 tile 内部边界的归一化跨边界阶跃异常最大值是 `6.32/1023`
  （满量程的 `0.62%`），放大图人工检查未见接缝；`visible_seam` 全为 0。
  可测到的局部代价是边界带 PSNR 比同图内部对照带低约 `1.47-1.53 dB`，
  但这不是丢列/重复列或可见亮度缝。
- 逐 CTU 码量之和与 tile entry payload 字节数逐 tile 对齐。`4x1` 和
  `2x2` 的误差全为 0 字节；`2x1`、`1x2` 及 `4x2` 的最后一个 tile 有
  1 字节差，来自 rbsp trailing/字节对齐。
- 高子带样本的结论是否定的：低子带确实被污染，不能确认“绝不污染”。
  QP 18/24/32 的低通 AC RMS 分别为 `1.497/2.528/4.242` 个 10-bit
  码值，QP 越高污染越强。

## 实验条件

- 输入：`work/tile_stress_1024x512_10b_420.yuv`，4 帧，25 fps。
- 编码：Kvazaar 2.3.2-c997f08，`medium`，全 I 帧，64x64 CTU，
  `loop_filter_across_tiles_enabled_flag=0`（更严格地隔离 tile）。
- 布局：`1x1`、`2x1`、`1x2`、`4x1`、`2x2`、`4x2`。
- 解码：FFmpeg 7.0.2 的 native HEVC decoder。
- 码率匹配：各布局分别微调 Kvazaar 目标码率，使实际大小尽量一致。

## 码流与 slice/entry point

每个布局有 4 个 I slice，每帧一个 slice。以 `4x2` 为例：

| 项目 | 值 |
|---|---|
| NAL 类型 | IDR_W_RADL |
| slice type | I |
| slice header | 120 bit |
| slice segment address | 0 |
| tile 数 | 8 |
| entry points | 7 |
| slice data | 54963 字节（首帧） |
| offset_len_minus1 | 12 |

`num_entry_point_offsets` 为 tile 数减 1；前 7 个 tile 由 entry point
给出长度，第 8 个 tile 由 slice data 剩余长度确定。逐 slice/entry 的
精确字段见 `results/tiles_*.slices.csv`，C++ 与 FFmpeg `trace_headers`
的字段值和 offset 列表一致，见 `results/stream_validation.txt`。

## 相同码率下的边界质量

| 布局 | 实际码率 | 文件字节 | 整帧Y PSNR | 边界带PSNR | 内部对照PSNR | 最大异常阶跃 | 可见缝 |
|---|---:|---:|---:|---:|---:|---:|---:|
| 1x1 | 10.504 Mbps | 220293 | 32.5868 | - | - | - | 0 |
| 2x1 | 10.551 Mbps | 221270 | 32.5969 | 31.3853 | 32.9143 | 5.0645 | 0 |
| 1x2 | 10.562 Mbps | 221494 | 32.5990 | 31.4240 | 32.8882 | 2.7859 | 0 |
| 4x1 | 10.564 Mbps | 221533 | 32.5990 | 31.4174 | 32.8893 | 6.1895 | 0 |
| 2x2 | 10.583 Mbps | 221932 | 32.6008 | 31.4012 | 32.9129 | 4.6438 | 0 |
| 4x2 | 10.620 Mbps | 222716 | 32.6065 | 31.4147 | 32.9015 | 6.3165 | 0 |

解释：

- tile 越多，slice header 和 entry point 开销增加，`4x2` 比 `1x1`
  多 2423 字节（约 1.1%）。
- 所有布局的整帧 PSNR 很接近；tile 划分没有造成明显全局质量塌陷。
- 边界带的 PSNR 系统性低于内部对照带约 1.5 dB，说明边界预测/量化条件
  更差；但跨边界阶跃的绝对异常不超过 6.33 个 10-bit 码值，没有形成
  可见缝或几何缺口。
- 本实验关闭了 `loop_filter_across_tiles_enabled_flag`。在该更严格
  配置下仍未形成可见缝，说明“独立熵编码”本身没有制造像素缺口；
  可测到的只是边界带局部量化质量下降。

## 高子带样本：低子带污染验证

样本每帧只有 2x2 高频棋盘（10-bit 值 480/640），低通 2x2 均值应恒为
512，所以源低带 AC RMS 为 `0.000000`。编码仍为 1024x512、10-bit
4:2:0、`2x2` tiles，只改变 QP。

| QP | 码率 | 低带 RMS | 低带 P99.9 | 低带最大偏差 | 判据 |
|---:|---:|---:|---:|---:|---|
| 18 | 1.898 Mbps | 1.4975 | 7.41 | 7.91 | 不通过 |
| 24 | 1.758 Mbps | 2.5280 | 11.82 | 16.43 | 不通过 |
| 32 | 1.590 Mbps | 4.2417 | 24.54 | 29.79 | 不通过 |

因此，“高子带量化噪声不会污染低子带”这一绝对结论不成立。HEVC 使用
块变换、量化和块边界滤波，并不提供理想子带隔离；尤其高 QP 下，块边界
和量化误差会把能量折叠到低带。若工程上要求低带不受污染，应放宽判据或
改用变换域/无损验证，而不能假设 HEVC 天然满足该性质。

## 关键文件

- `results/summary.csv`：布局级码率、PSNR、接缝指标。
- `results/tile_boundaries.csv`：所有 tile 的像素边界和 CTU 边界。
- `results/tile_stats.csv`：每个 tile 的 CTU 数、码量、方差。
- `results/tiles_*.slices.csv`：slice header 与逐个 entry point。
- `results/tiles_*.ctu.csv`：每一帧每个 CTU 的 bits 和类型。
- `results/tiles_*.seams.csv`：每条内部边界的接缝测量。
- `results/subband_qp_sweep.csv`：高子带样本的 QP 扫描。
